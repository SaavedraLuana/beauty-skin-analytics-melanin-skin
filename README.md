# 💄 Skin Care Data Lab

This project analyzes my personal skincare routine using SQL.

## 🎯 Objective
Understand how skincare products affect skin health metrics like:
- Glow
- Hydration
- Irritation
- Texture

## 🧴 Dataset
Real personal skincare routine including:
- Vitamin C
- Retinol
- Salicylic acid
- Barrier repair creams

## 📊 Key Questions
- Which products improve skin glow?
- Which products cause irritation?
- Morning vs night routine performance

## 🛠 Tools
- SQL
- GitHub
- Data analysis
