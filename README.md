# beauty-skin-analytics-melanin-skin
# Skin Care Data Lab 💄

This project tracks skincare routines and skin health using SQL.

## 🎯 Goal
Understand how skincare products affect:
- Hydration
- Texture
- Irritation
- Glow

## 🧴 Why this project?
This is a real-life dataset based on a melanin-rich skin routine, where hydration, irritation control, and hyperpigmentation are key factors.

## 📊 Files
- skincare_log.csv → daily routine tracking
- skin_metrics.csv → skin condition tracking
- SQL files → analysis queries

## 🧠 Key Questions
- Which products improve skin glow?
- What causes irritation?
- How does skin change over time?

## 🛠 Tools
- SQL
- Data analysis
- Excel / CSV
